# Week 0 — Scratch

## Byte Defender

My CS50x Week 0 project, built in Scratch.

**What it is:** an interactive project featuring:
- 🛡️ **Shield Guide** — an interactive guide character that asks the player questions, reacts with
  conditional logic (`if/else`), and uses **custom blocks** (procedures I defined myself)
- 🐞 **Bug Buddy** — a sprite that roams the stage in a `forever` loop, bouncing off edges,
  appearing and disappearing
- 🏁 **Score system** — a `Score` variable initialized on green flag, driven by broadcast events

**Concepts used:** events & broadcasts, variables, conditionals, loops, user input (`ask`/`answer`),
custom procedures.

**File:** `byte_defender_cs50_scratch_3_p8bi.sb3` — open it in the
[Scratch editor](https://scratch.mit.edu/projects/editor/) or download and open with Scratch.

**Status:** ✅ Complete — built by me as my Week 0 project.
